## 📌 Overview

A modern, responsive, high-performance personal portfolio website built with clean HTML5, CSS3 (Vanilla CSS with design system tokens and fluid clamp typography), and modular JavaScript.

## 🚀 Key Features

- **Dynamic Typography & Design**: Built with Plus Jakarta Sans and DM Mono, using a sleek dark luxury aesthetic with warm champagne gold accents.
- **Fluid Responsiveness**: Engineered to adapt cleanly from 320px mobile screens up to 1920px+ ultra-wide desktop displays.
- **Interactive Project Showcase**:
  - **Kemet Gate**: Interactive digital tourism platform (Digilians Flagship Graduation Project).
  - **HR & Payroll Management System**: Enterprise workforce and payroll operations portal.
  - **Shopery**: Full-stack e-commerce application with dynamic catalog, cart, and admin dashboard.
  - **Topico**: Vanilla JS e-commerce & community portal consuming REST APIs.
  - **Diabetes Management App**: Machine learning prediction and health analytics app (Zagazig University B.Sc. Graduation Project).
- **Interactive Modal & Drawer**: Lightweight lightbox with full keyboard accessibility and touch navigation.
- **Resume Download**: Integrated verified PDF resume download.

## 🛠️ Tech Stack

- **Frontend**: HTML5, CSS3 (Custom CSS Architecture, Flexbox, CSS Grid), Vanilla JavaScript (ES6+)
- **Typography**: Plus Jakarta Sans, DM Mono, Instrument Serif
- **Assets**: Optimized project screenshots, compressed vectors, and verified credentials

## 💻 Local Development

To preview the portfolio locally:

```bash
# Using Node.js built-in server
node server.js
```

Then navigate to `http://localhost:8080` in your web browser.
